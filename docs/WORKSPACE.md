# Workspace shell

Startup is empty. Characters, Monsters and Encounter have record controls; other tools open blank panels. Records appear only after the user adds them.

## Navigation

The green menu button stays visible in both sidebar states. Collapsing navigation reduces it to a 56-pixel green rail and gives the remaining width to the workspace. No additional sidebar appears. Expanded navigation is 220 pixels on desktop and 190 pixels on small screens.

## Panels

Use navigation or Open a tool to open a panel. Drag tabs between panels or onto an edge to dock. The split icon provides the same placement options without dragging. Drag dividers, or focus them and use arrow keys, to resize.

The … menu sets visibility priority, moves or reorders tabs, collapses panels, or hides tools. Panels displaced by limited space stay available in the restore bar. Text sizes do not shrink to fit more panels.

## Layouts

Save layout stores a named arrangement on this device. Layouts loads or deletes named layouts, restores the previous arrangement, or resets to an empty workspace. Saving over a name requires selecting Replace.

The shell stores preferences under waypoint-shell-settings. Existing IndexedDB campaigns and waypoint-settings preferences remain untouched. New projects contain only user-entered names and layouts; they contain no seeded campaign records.

Floating windows and walkthroughs are not active. See ACTORS.md for character creation, monster presets, PDF attachments and encounter health controls.
